# 訊息一致性檢查與標題鏡射

主檔 `SKILL.md` 硬規則 1 的展開。**任何 LIFT 診斷之前先跑這一條。**

## 三方比對的實際做法

### 步驟一：把三方的「主張」各抽成一句話

不要拿整頁文字跟整段廣告文案硬比——那會變成語感判斷，兩個人會有兩種結論。先各抽一句：

| 比對對象 | 從哪裡抽 | 抽出來長什麼樣 |
|---|---|---|
| **①切角文件** | 「這檔要打誰、憑什麼贏、對比誰」那一段 | 「打不想再手動對帳的中小電商老闆，賣點是自動串接三大平台，對比的是請工讀生手動整理」 |
| **②廣告素材** | 使用者**真正看到並點下去**的主張——標題、主要文案前 125 字元、視覺上最大的那句話 | 「三大平台訂單自動對帳，不用再請工讀生」 |
| **③到達頁上方可見區塊** | 首屏（不捲動就看得到）的 H1、副標、主 CTA 文字 | 「電商營運的最佳夥伴」 |

**②要抽的是「使用者實際看到的」，不是「我們規劃的訊息」。** 這個區別很重要——實際跑的素材常常跟當初的規劃不一樣（換過素材、A/B 測試留下另一版、平台自動組合），拿規劃文件去比等於沒比。要跟使用者要**實際在跑的廣告文案**，拿不到就明講「這次比對用的是規劃文件而非實際素材，可能有落差」。

### 步驟二：判定

上面那個例子：②③明顯不一致——廣告承諾「自動對帳、不用請工讀生」，頁面首屏卻是「電商營運的最佳夥伴」這種誰都能講的話。點進來的人在 5 秒內找不到他被承諾的東西，就走了。

判定與處置見 `SKILL.md`「硬規則 1」的表格。這裡補充**②③一致但跟①對不上**這種情況為什麼不能自己動手改：那代表執行層偏離了策略，可能是切角改了沒同步、也可能是執行時發現原本的切角打不動而自己調整了。**這兩種情況的正確處置完全相反**（前者要把執行改回來，後者要回頭改切角），判斷需要的資訊不在到達頁上。如實回報，讓使用者決定。

## 六種常見的不一致型態

| 型態 | 長什麼樣 | 為什麼會發生 |
|---|---|---|
| **具體 → 籠統** | 廣告「三大平台自動對帳」，頁面「電商營運的最佳夥伴」 | 頁面是給所有流量共用的官網首頁，不是為這支廣告做的到達頁 |
| **優惠消失** | 廣告「首購 8 折」，頁面首屏完全沒提折扣，要捲到第三屏才看到 | 廣告端臨時加了促購訊息，頁面沒同步 |
| **受眾錯位** | 廣告打「小資族」，頁面通篇在講「企業導入」 | 一個頁面接了多支不同受眾的廣告 |
| **價格預期落差** | 廣告「免費試用」，頁面首屏就要求輸入信用卡 | 廣告端為了 CTR 放大了「免費」，頁面照實呈現流程 |
| **行動落差** | 廣告 CTA「立即預約」，頁面主 CTA 是「加入 LINE 好友」 | 轉換路徑中途改過，廣告沒改 |
| **語氣落差** | 廣告是口語化的原生感文案，頁面是制式的企業官網語氣 | 素材與頁面由不同人／不同時期做的 |

**「價格預期落差」與「行動落差」這兩型要特別小心，它們不只是轉換問題**——廣告承諾的東西頁面兌現不了，在台灣同時是公平交易法對不實廣告關注的範圍。發現這兩型時，除了建議修正，要明講這一層風險。

## 標題鏡射（②③不一致時最直接的修法）

Meta 是現存最好的分割測試工具之一——廣告標題的**曝光量通常遠大於實際點擊到到達頁的流量**，代表你能在 Meta 上更快拿到「哪個標題有共鳴」的訊號，再把它搬到到達頁。

做法：

1. 用多個不同標題跑廣告版本（原版建議 20-40 個，實際數量依帳戶流量與預算調整——**流量太小時樣本不足，數字不必然可信**，樣本量門檻見 `campaign-analysis-iteration`）
2. 找出表現較好的標題。**注意 RSA 與 Meta 動態素材沒有單一標題層級的轉換資料**（標題會被系統隨機組合），要比單一標題就得拆成獨立的廣告去跑——這個限制的完整說明在 `campaign-analysis-iteration` 的分析單位規則
3. 把該標題**原封不動搬到到達頁**——H1、副標、內文開頭都用一樣的字句。不是「意思相近」，是**一樣的字**
4. 這個改動在實務案例中常帶來到達頁轉換率的提升，但**幅度因網站與受眾而異，不要引用單一案例的提升幅度當保證值**，建議實際測試後再對客戶端報告具體數字

**原理（這是待驗證的假設，不是保證）**：點進去的人期待的是那個承諾。到達頁用一模一樣的字句回應時，語感（scent）對得上，**這被認為能降低點擊後立刻離開的比例**；換了角度時，即使頁面本身做得好，**也可能**在這裡流失。

**寫進報告時要用假設語氣**：「鏡射後轉換就會發生」「跳出率都會飆高」這類斷言不能寫——那是保證，違反 `SKILL.md` 硬規則 2。而且**訊息一致性未必是這個頁面最大的問題**：它排第一是因為修正成本低且會影響後續所有文案建議，不是因為它必然影響最大。實際影響多大要靠測試才知道，樣本量門檻見 `campaign-analysis-iteration`。

**一個頁面接多支不同角度廣告時怎麼辦**：標題鏡射跟「一頁通吃」是衝突的。三種處理方式，成本由低到高：

1. **收斂廣告角度**——只留下跟頁面主張一致的那幾支，其餘停掉（成本最低，但犧牲角度覆蓋）
2. **動態標題置換**（URL 參數帶入 → 頁面 H1 依參數切換）——**注意這會把行銷參數放進網址，且置換內容若來自 query 就是使用者可控的輸入**，要做白名單對應（參數值只能對應到後端預先定義的幾組文案，不是直接把參數值渲染進頁面，否則就是 XSS 與內容注入）；網址帶參數的個資外洩面另見 `tracking-health` 技能
3. **一角度一頁**——最乾淨，成本最高，適合主力角度
