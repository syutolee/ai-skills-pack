# 診斷：數字不好時該先查哪裡

**這份檔案回答「該修哪裡」，不回答「該不該觸發關閉門檻」**（那是 [kill-keep-scale.md](kill-keep-scale.md)）。用之前一樣要先過 [evidence-gates.md](evidence-gates.md) 的三道關卡——對雜訊做診斷跟對雜訊做判決一樣沒有意義。

## 依目標看核心指標

| 目標 | 主要指標 |
|------|----------|
| 認知 | CPM、觸及、影片觀看率 |
| 考慮 | CTR、CPC、網站停留時間 |
| 轉換 | CPA、ROAS、轉換率 |

**拿錯目標的指標去判斷是常見的誤診來源**：用轉換目標的 CPA 去評價一支跑「觸及」目標的廣告，它一定「表現很差」，但那只是因為平台從來沒有在幫它找會轉換的人。

## 指標層級的優化槓桿

### CPA 太高

依序檢查，**順序是刻意的——由外而內，先排除不是廣告本身的原因**：

1. **檢查到達頁**（問題是不是出在點擊後？）——CTR 正常但 CPA 高，通常代表流量進來了卻沒轉換，這是到達頁的訊號不是素材的訊號，走 `landing-page-cro`
2. **檢查追蹤**——CPA 突然變高但實際訂單沒少，先確認轉換有沒有正常回傳，走 `tracking-health`
3. 收緊受眾投放（`ads` 的受眾設定）
4. 測試新的素材角度（`ad-creative`）
5. 提升廣告相關性／品質分數
6. 調整出價策略

### CTR 偏低

- **素材沒共鳴** → 測新鉤子／新角度
- **受眾不對** → 重新檢視投放設定
- **素材疲乏** → 更新素材（疲乏的判定門檻見 [kill-keep-scale.md](kill-keep-scale.md)「疲乏偵測」）

### CPM 偏高

- **受眾太窄** → 放寬投放
- **競爭激烈**（檔期、旺季）→ 嘗試不同版位
- **相關性分數低** → 改善素材貼合度

## 素材診斷漏斗（影片與靜圖都適用）

廣告表現不好時，看漏斗找出該修哪個部分，不要整支廣告直接放棄。**「弱的話最先該檢查的方向」不是唯一原因**——每一段都列了其他可能，看到弱訊號就直接斷定單一原因是這份表最想避免的錯誤：

| 階段 | 指標 | 最先該檢查的方向（不是唯一原因） | 怎麼修 |
|---|---|---|---|
| **停下** | 3 秒觀看率 | 視覺動作（跟字幕）——但也可能是版位、頻率疲乏、或受眾本身跟廣告不相關 | 先換新的視覺開場測一輪，同時排除版位／疲乏因素 |
| **留下** | 停留率（3秒→15秒） | 承接鉤子的過渡段——但也可能是內容本身對這個受眾不夠有共鳴 | 重寫 3-15 秒，**不是重寫鉤子** |
| **點擊** | CTR | 渴望／優惠不夠清楚——但也可能是出價策略把廣告投給了不感興趣的受眾 | 收斂承諾、CTA、或證明力道；同時檢查受眾與出價設定 |
| **轉換** | 點擊後轉換率 | 承接不連貫（到達頁沒有延續廣告的承諾）是常見原因之一，**但不是唯一可能**——受眾與優惠本身不合、價格／流程的摩擦、出價策略帶來低意圖流量、歸因窗設定跟實際購買週期不合，都可能造成弱轉換率 | 檢查到達頁一致性（`landing-page-cro` 的訊息一致性檢查）**之前**，先確認流量品質（受眾／出價／歸因窗）沒有問題 |

**一個好的 3 秒開場不代表是一支好廣告**——誘導性視覺會吸引錯的觀眾，會出現高 3 秒觀看率＋停留率／轉換率崩掉的組合。宣布任何結論前要看完整個漏斗。

**每輪測試只改一個元件**（視覺、過渡段、或優惠呈現方式擇一）——同時改三樣然後看到改善，你不會知道是哪一樣造成的，下一輪也複製不了。

## 投遞面 vs 品質面：先分清楚再診斷

這是最容易誤診的分岔口。**低花費、低曝光、零轉換，可能是「平台不想給它量」也可能是「它根本沒有資格拿量」**，兩者的處置完全相反：

- **投遞資格問題**（審核被擋、排程沒涵蓋觀察期、組層級出價上限太低、受眾重疊、素材規格被特定版位拒絕）→ **修設定，不是換素材**。四項診斷清單在 [kill-keep-scale.md](kill-keep-scale.md)「投遞診斷」，fail closed：診斷沒過就不觸發關閉門檻
- **品質問題**（資格都正常、也拿到足夠花費，但成效就是不好）→ 這時候才輪到素材與優惠的診斷

**零花費比低花費更常是資格問題**，不是降權。
